## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git (for development)
- Text editor (VS Code recommended)

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vittaraglobel/vittaraglobel.github.io.git
   cd vittaraglobel.github.io
   ```

2. **Open locally:**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Or using Node.js (live-server)
   npx live-server
   ```

3. **Visit:** Open `http://localhost:8000` in your browser

### Making Changes

1. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Edit HTML/CSS/JS files

3. Test locally

4. Commit and push:
   ```bash
   git add .
   git commit -m "Description of changes"
   git push origin feature/your-feature-name
   ```

5. Open a Pull Request on GitHub

## 🎨 Customization

### Color System
Update CSS variables in any HTML file's `<style>` tag:

```css
:root {
    --navy: #0A1628;              /* Primary dark color */
    --gold: #C9A84C;              /* Accent color */
    --off-white: #F8F6F1;         /* Background */
    --text: #2C2C2C;              /* Primary text */
}
```

### Typography
- **Display Font:** Playfair Display (serif) - headings
- **Body Font:** DM Sans (sans-serif) - text

### Spacing & Layout
- Base padding/margin: multiples of 8px (8, 16, 24, 32, 40, 48, etc.)
- Max content width: 1280px
- Mobile breakpoint: 768px

## ⚡ Performance Optimization

### Implemented Strategies
- ✅ CSS Grid & Flexbox for efficient layouts
- ✅ CSS variables for consistency and maintainability
- ✅ Minimal JavaScript (no frameworks)
- ✅ Google Fonts with `display=swap` for font loading
- ✅ Semantic HTML for faster rendering
- ✅ Gzip compression enabled on GitHub Pages
- ✅ Async/defer script loading where applicable

### Core Web Vitals Targets
- ⏱️ First Contentful Paint: < 1.5s
- 📊 Largest Contentful Paint: < 2.5s
- 🎯 Cumulative Layout Shift: < 0.1
- ⚡ Time to Interactive: < 3.5s

**Test your performance:** Use [Google PageSpeed Insights](https://pagespeed.web.dev/)
